# Security policy

## Reporting a vulnerability

Please don't open a public issue or pull request for a security problem.
Report it privately instead, via
[Report a vulnerability](https://github.com/newbenji/charts/security/advisories/new)
under this repository's **Security** tab.

That covers the charts themselves (e.g. an insecure default in a template)
as well as this repository's CI and release pipeline. Problems in the
upstream applications or container images the charts deploy should go to
those projects.

## Supported versions

Only the latest released version of each chart gets fixes.
